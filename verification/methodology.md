# Public verification methodology

Silex verification is an evidence-oriented process for reviewing public project information.

1. Identify the public project and review scope.
2. Collect relevant public evidence.
3. Record observations with sources and timestamps.
4. Distinguish observed facts from interpretation.
5. Publish limitations and unresolved items with the report.

Verification is not a guarantee of safety, performance, ownership, liquidity, or future behavior. Internal providers, thresholds, private workflows, bypasses, and anti-abuse controls are intentionally not documented here.
